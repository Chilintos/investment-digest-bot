# Investment Digest Bot

Персональный Telegram-бот для сбора новостей по финансовому инструменту из фиксированного списка каналов.

## Возможности (MVP)
- 📥 Сбор постов из 5 Telegram-каналов через Telethon (userbot)
- 🔍 Фильтрация по тикеру/названию (case-insensitive + синонимы из `aliases.json` + простая морфология)
- 📅 **6 периодов:** день / неделя / месяц / квартал / полугодие / год
- 📋 Выдача хронологического списка (дата — канал — **полный текст** — ссылка)
- 🎯 **Заголовки новостей выделены жирным** (дата + канал)
- 💾 Автосохранение дайджеста в `Reports/` в Markdown
- ⚠️ Дисклеймер: не финансовый совет, проверяй факты по первоисточникам

## Быстрый старт

### 1. Зависимости
```bash
pip install -r requirements.txt
```

### 2. Настройка секретов
Скопируй `.env.example` в `.env` и заполни:
```bash
cp .env.example .env
```
Получи `api_id` и `api_hash` на https://my.telegram.org  
Получи `TELEGRAM_BOT_TOKEN` у @BotFather

### 3. Первый сбор данных
```bash
# За месяц (30 дней)
python -m main fetch --days 30

# За неделю (7 дней)
python -m main fetch --days 7

# За день (1 день)
python -m main fetch --days 1
```
Это скачает посты за указанный период из всех 5 каналов в `data/messages.csv`.

### 4. Запуск бота
```bash
python -m main bot
```
Бот будет доступен в Telegram.

### 5. Тест поиска (без бота)
```bash
python -m main search SBER --period month --max 10
python -m main search SBER --period week --max 10
python -m main search SBER --period day --max 10
```

### 6. Работа через Telegram-бот

После запуска бота (`python -m main bot`) откройте Telegram и найдите своего бота по username (указанному при создании через @BotFather).

**Интерфейс бота:**

| Элемент | Описание |
|---------|----------|
| **Reply-клавиатура (снизу)** | 📅 День, 📅 Неделя, 📅 Месяц, 📅 Квартал, 📅 Полугодие, 📅 Год, 🔄 Новый запрос, ℹ️ Помощь |
| **Команды** | `/start` — начало, `/new` — новый запрос, `/fetch` — собрать свежие посты, `/help` — справка |

**Способы запроса дайджеста:**

1. **Текстом (один сообщением):**
   ```
   SBER неделя
   Газпром месяц
   AAPL квартал
   ```
   Бот сразу вернёт дайджест за указанный период.

2. **Пошагово:**
   - Напишите тикер: `SBER`
   - Бот ответит: «Принято: SBER. Выберите период кнопкой снизу 👇»
   - Нажмите кнопку периода (например, 📅 Неделя)

**Результат выдачи:**
- Заголовок новости: **дата + канал** (жирным шрифтом)
- Полный текст поста (без обрезки)
- Ссылка «Открыть в Telegram»
- Дисклеймер: *«Это сводка по открытым каналам, не финансовый совет...»*

**Inline-кнопки под результатом:**
- 🔄 **Сменить тикер** — ввести новый тикер
- 📅 **Сменить период** — выбрать другой период для текущего тикера

**Автосохранение:** каждый дайджест автоматически сохраняется в папку `Reports/` в формате Markdown (`digest_SBER_week_2026-11-25_14-30-45.md`).

**Длинные сообщения** автоматически разбиваются на части (лимит Telegram — 4096 символов).

## Как это работает

### Сбор (`fetch.py`)
1. Telethon userbot подключается к Telegram от **твоего аккаунта** (нужен номер + код)
2. Итерируется по 5 каналам из `config.yaml`
3. Скачивает сообщения за N дней назад (`--days 1/7/30/90/180/365`)
4. Сохраняет в CSV: `channel_id`, `channel_name`, `message_id`, `date`, `text`, `has_media`, `views`, `forwards`
5. Дедуплицирует по `message_id` (инкрементально, повторный запуск дописывает только новые)
6. Обрабатывает `FloodWait` (ждёт и повторяет)

### Поиск (`search.py`)
1. Загружает CSV в pandas DataFrame
2. Строит термины: запрос + синонимы из `aliases.json` + простые словоформы (s/es, а/я/ы/и...)
3. Фильтрует по регексу (граница слова, case-insensitive)
4. Фильтрует по периоду (дни назад: day=1, week=7, month=30...)
5. Сортирует по дате (ascending = старые → новые)
6. Берёт топ-N самых свежих, для бота — переворачивает в хронологическом порядке

### Бот (`bot.py`)
- **Reply-клавиатура снизу:** 📅 День, 📅 Неделя, 📅 Месяц, 📅 Квартал, 📅 Полугодие, 📅 Год, 🔄 Новый запрос, ℹ️ Помощь
- **Ввод текстом:** `SBER неделя`, `Газпром месяц`, `AAPL квартал`
- **Inline-кнопки под результатом:** 🔄 Сменить тикер, 📅 Сменить период
- **Выдача:** заголовок (дата + канал — **жирным**), полный текст, ссылка
- **Длинные сообщения** автоматически разбиваются на части (≤4000 символов)
- **Автосохранение** в `Reports/digest_<тикер>_<период>_<timestamp>.md`
- Команды: `/start`, `/new`, `/fetch`, `/help`

## Синонимы тикеров (`config/aliases.json`)
```json
{
  "SBER": ["сбер", "сбербанк", "sberbank"],
  "GAZP": ["газпром", "gazprom"],
  ...
}
```
Если пользователь ввёл «сбер» — найдёт и «SBER», и «сбербанк», и «sberbank».

## Ограничения MVP
- Только 5 заданных каналов
- Простой поиск подстроки (нет LLM, нет семантики)
- Нет консолидации по темам
- Нет тональности/сигналов
- Данные только из Telegram (нет RSS/сайтов)

## Безопасность
- `.env` в `.gitignore` — никогда не коммить секреты
- Userbot читает только публичные каналы
- Никакие данные не уходят наружу
